# Vision
Este é um projeto que pretende desenvolver uma plataforma de ecommerce segura, que permita cadastrar produtos no catálogo, adicionar ou remover itens no carrinho de compras, criar perfil autenticado para os clientes, garantir a confiabilidade das transações e persistência da intenção de compras em caso de abandono de carrinho.

A plataforma deve sustentar a loja virtual e ser capaz de operar de forma contínua e automatizada.

## Problema
Comerciantes precisam vender produtos online com sua própria marca, mantendo uma operação confiável e integrada aos serviços de pagamento, comunicação e transporte.

## O que é? 
- Plataforma white-label e single tenant, com uma instância própria por comerciante e sua identidade visual.
- Permite cadastro de produtos no catálogo.
- Permite integração com gateways de pagamento.
- Armazena os itens do carrinho em caso de jornada incompleta.
- Notifica o usuário via e-mail e whatsapp via integração.
- Frontend responsivo 


## O que não é? 
- Não é um gateway de pagamento. 
- Não faz gerenciamento de transporte apenas notifica via integração com transportadora.
- Não é um ERP de gerenciamento de estoque, 
- Não armazena dados de pagamento. 
- Não faz gerenciamento de fluxo caixa ou controle financeiro. 
- Não implementa solução nativa de notificação via e-mail ou whatsapp.
- Não implementa nativamente canal de SAC. 
- Não emite notas fiscais.
